# Teacher Decision Lab

An independent React + TypeScript introductory lesson for novice preschool teachers. No student data, accounts, or analytics.

Run `npm ci` and `npm run dev` with Node 22.13+ (or Node 24). Open the URL ending in `/teacher-decision-lab/`. Run `npm run build` to type-check and generate the static site in `dist/`.

The Pages workflow expects GitHub Actions as the Pages source. The Vite base matches the intended public project URL. Do not change the portfolio CTA until the deployed lesson and its assets have been verified.

The three screens end at the scenario introduction. Decision options, feedback and branching are intentionally not implemented. The classroom image is an AI-generated editorial illustration, not evidence of a real classroom event.
